## 历史差异

| 项目 | v1 | v2 | v3 |
|---|---|---|---|
| 输出分辨率 / ViT输入 | 512 / 224 | 512 / 448 | 256 / 224 |
| ViT取特征层 | 32 | 8、16、24、32 | 8、16、24、32 |
| 深层投影 | 单层1280→512 | 四路投影＋融合 | 同v2 |
| CNN | 普通卷积 | 浅层和瓶颈多尺度膨胀卷积 | 同v2 |
| 可训练参数 | 13.421M | 24.885M | 24.885M |
| 历史任务 | 线性强度回归 | 线性强度回归 | log强度回归 |
| 历史loss | MSE，通道1/σ | 同v1 | MSE，阳性像素权重11、背景1 |
| 每次更新有效batch | 16，单卡 | 8，单卡累积2次 | 256，4卡DDP |
| 最终权重选择 | 指定迭代 | 最后epoch | 验证集best |

32层ViT的Q/V原本均有LoRA。v2/v3权重结构相同，但目标域、分辨率、训练配置和权重值不同。完整逐字段配置、训练过程及指标口径差异见 [三版审查报告第4节](audit_20260925/代码检查与三版差异.md) 与 [配置对照CSV](audit_20260925/checkpoint_config_diff.csv)。历史PSNR/SSIM只留作归档，新流程不计算这些指标。
