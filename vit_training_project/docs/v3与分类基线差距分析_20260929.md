# v3与分类基线差距：采样、任务与患者分布

分析对象是已完成的旧分类基线，不是刚启动的阳性Dice实验。后者还没有完整验证结果。本文只读已有结果，不改变正在运行的训练。

## 已确认的差距

共同独立测试病例CRC02、6,638张patch：v3与分类基线macro F1分别0.48294、0.47917，差0.00377；IoU分别0.35686、0.35937，分类基线略高。AP分别0.45903、0.42559，分类基线低0.03344。不是所有通道或所有指标都下降。

同一组权重的微调效果不能仅凭“采用分类、Dice、平衡采样”来保证。v3和分类基线本来就都是32层Q/V LoRA、rank32，四层特征和相同的ViT输入尺度；新流程没有额外增加LoRA覆盖范围。

## 最直接证据：患者表达分布不同，阈值迁移后假阳性增多

| 通道 | v3自身验证集阳性比例 | 分类基线自身验证集阳性比例 | CRC02阳性比例 |
|---|---:|---:|---:|
| PDL1 | 2.06% | 16.73% | 1.52% |
| CD45RO | 6.16% | 21.69% | 1.19% |
| CD20 | 0.93% | 10.75% | 0.68% |

这些比例按参与监督的有效像素统计，不是全组织表达率。不同验证集是由于训练患者划分不同；不能用分类基线的验证集给旧模型调阈值，因为它们大部分曾用于旧模型训练。

PDL1最能体现阈值操作点问题：分类基线按统一验证搜索网格选出的概率阈值是最低边界1/256。在CRC02上，它预测6.24%的有效像素为PDL1阳性，而GT只有1.52%；Precision=0.144、Recall=0.593、F1=0.232。v3预测阳性比例1.35%，Precision=0.454、Recall=0.403、F1=0.427。两者PDL1的AP却接近：0.341与0.347。因此，这个通道的巨大F1差距不能简单解释为模型完全不会辨别，阈值迁移和患者表达率变化是重要因素。

这仍不是仅由上述比例就证明的因果分解；不同模型分数分布和校准也有影响。v3强度阈值和当前概率阈值的数值不能直接比较大小。

CD45RO还存在明显排序差距：AP从v3的0.447降至当前0.235；CD31从0.272降至0.156，CD3e从0.377降至0.267。这部分不能仅靠调整一个固定阈值解释。AUROC/AP为统一256-bin近似，进一步精细比较可提高分辨率，但不能在测试集选择最佳阈值或训练方案。

## 采样确实没有实现最终训练分布的逐通道1:1

各通道自己的清单是false:true1:true2=2:1:1，但这些清单合并之后，抽到的patch会监督全部有效通道，其他通道的标签组成又会改变最终边际比例。

| 通道 | 合并后训练清单的阴性patch比例（原生标签） |
|---|---:|
| Hoechst | 0.43% |
| CD31 | 25.62% |
| CD8a | 19.30% |
| CD45RO | 31.35% |
| FOXP3 | 45.13% |
| Ki67 | 47.04% |

更隐蔽的一点是，不同通道清单长度差别很大。Ki67清单152,092行，FOXP3清单134,160行，两者合计占最终738,752行的38.75%；Hoechst清单只有680行。因此“合并后随机抽patch”不等于“均匀选择一个通道，再在其分层中抽patch”。这改变了组织/病例组成，而不是让其他通道没有loss：每个patch仍监督全部有效通道。

最终清单738,752行只包含218,672个不同patch，重复不能增加患者多样性。相对自然训练分布，CRC04的抽样份额被放大到1.40倍，CRC27约0.79倍。说明确有分布偏移，但这些证据尚不能证明采样是性能差距的唯一或主要原因。

此外，patch层面的阳性与阴性数量平衡，不等于像素平衡：一个阳性patch里仍可能只有极少阳性像素。

## v3和当前基线还有训练目标及数据量差异

v3使用log强度回归，保留连续强弱信息；其前景加权MSE对满足历史前景定义的像素权重为11、背景1，通道权重在log模式下为均匀权重。分类基线将GT按>0变成二值标签，使用MSE+Dice和约0.86～1.10的通道1/σ权重。这个σ来自阳性强度，不是二值阳性频率；它不会自动使正负像素贡献平衡。Dice有另一种不平衡补偿作用，不能把两个目标简单视为等价。

将强度变为二值会丢失强弱信息，弱非零背景也可能被算阳性；是否确有标签噪声需要单独核查，目前不能确认它是主因。

历史v3训练295,096张、37张切片/36例真实患者；旧分类基线自然训练226,465张、29例患者。训练病例覆盖与样本量并不相同，不能把比较结果完全归于“哪种微调更好”。

旧分类基线的空目标Dice惩罚问题已经在新实验修正，但它不是上述所有差异的通用解决办法，也不能保证一次修改就超过v3。

## 后续比较顺序

1. 让已启动的阳性Dice实验形成验证结果，不在中途再改变采样和loss，避免混合多个无法追溯的干预。
2. 比较时固定修正后的患者划分、模型初始化、训练更新预算和验证指标；原旧基线还包含CRC33身份错误，因此若要严格分离loss影响，需要在修正后的同一划分补齐对应基线。
3. 采样对照优先比较自然采样与“保留自然覆盖、限制重复次数的通道分层采样”。不要强行让所有通道每批都1:1：Hoechst可信阴性极少，强制均衡会反复抽同一小批patch。
4. 阈值应在验证患者之间检查稳定性，报告逐患者Precision/Recall/AP。可在验证内部做留一患者检查或按患者宏平均选阈值；不能看到CRC02结果后直接为CRC02调阈值。
5. 对CD45RO/CD31/CD3e等排序能力差距大的通道，再比较像素级正类权重、标签定义和保留强度信息的辅助目标。每次只改变一个因素，不据现有结果直接指定最优权重。
