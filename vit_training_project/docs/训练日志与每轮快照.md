## 输出内容

- `train.log`：首批、每 50 批输出当前及平均 train loss、训练速度、当轮训练已用时间和预计剩余训练时间；每轮结束输出 train loss、val loss、macro IoU、macro F1、学习率和耗时。
- `results/model/progress.json`：最新训练进度。训练阶段剩余时间的估计不包含随后验证、保存 checkpoint 的时间。
- `results/model/train_log.csv`：每轮汇总，包括 train/val loss、macro IoU/F1、学习率、训练/验证/合计耗时、累计耗时和快照文件名。耗时统计覆盖训练与验证（含快照），不含该轮 checkpoint 保存和后续曲线写盘。
- `results/model/epoch_metrics/epoch_NNN.json`：当轮所有通道的 precision、recall、F1/Dice、IoU、specificity、AUROC/AP 直方图估计、混淆矩阵等。
- `results/model/classification_history.json` 和 `.png`：历史曲线。
- `results/model/last.pt`、`best.pt`：最新和最佳 checkpoint。
- `results/model/snapshot_patch.json`：固定验证 patch 的身份。选取 rank 0 固定首批中阳性标签最多的 patch，不随 epoch 改变。
- `results/model/snapshots/epoch_NNN_patch_ID.png`：H&E、原始 GT mIF 可视化、GT 表达标签、预测虚拟 mIF 概率合成图。
- 同目录 `epoch_NNN_patch_ID_channels.png`：16 个通道的 GT 标签与预测概率对照。
- 同目录 `epoch_NNN_patch_ID.npz`：未阈值化的 16 通道概率、GT 标签（255 为忽略）、通道名、patch ID 和 epoch。预测在 H&E 玻璃背景中置零。

虚拟 mIF 为独立多标签表达概率，并非回归荧光强度。原始 GT 面板逐通道做 99.5 分位显示拉伸，预测概率不做强度拉伸，两者不能按亮度直接比较定量误差。模型选择指标固定使用 0.5；训练结束后仅用验证集确定各通道阈值，再锁定用于测试。

完整验证 loss 在各卡遍历完全部验证样本后，统一汇总逐通道 MSE 分子/有效像素数与逐图逐通道 Dice 损失/有效图数。不丢弃尾批，也不因某卡无验证样本产生 NaN。

启动前已通过 13 项单元检查、四进程全局梯度与不等长验证检查，以及两轮微型模型生产训练流程检查（包括快照、loss、早停、恢复、阈值校准、测试和预测）。这些检查使用 CPU 微型模型；真实四卡模型由显存校准和正式训练进一步验证。
