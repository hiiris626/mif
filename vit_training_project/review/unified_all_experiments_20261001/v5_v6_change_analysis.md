# v5 → v6 改动与提升分析

## 未改变的部分

- 同一患者划分、训练清单和随机种子。
- 训练集 223,400 patch，每轮无放回随机打乱；每卡 batch 64，四卡全局 batch 256。
- 相同 ViT + LoRA + CNN decoder 架构。
- BCE 与 all-valid Dice 系数均为 1。

## 实际改变

1. **监督有效掩膜扩大**：v5 只监督旧 `eligible` 区域；v6 使用“通道可用 AND H&E组织”。每个通道训练有效像素由 8,159,405,125 增加到 11,022,356,541，增加 2,862,951,416（35.09%），新增部分几乎全部是组织内标签0。
2. **移除逐通道阳性 BCE 强加权**：v5 使用 `N_negative/N_positive`，例如 CD31 44.48、FOXP3 122.25、CD8a 24.93、CD20 43.50；v6 所有正负像素权重均为1。
3. **移除强度标准差外层通道权重**：v5 默认使用约0.862–1.103的旧强度权重；v6外层16通道均为1。该变化幅度较小，预计不是主要来源。

## 统一测试结果

共同CRC02、6,638 patch、组织内全阴性参与评价。

- 各自验证集阈值：v5→v6，宏F1 0.42068→0.45336，precision 0.35048→0.38933，recall 0.63231→0.63020。召回基本不变，提升主要来自precision。
- 同口径聚合阴性像素误报率：7.064%→4.597%；假阳性像素从373,772,443降到243,236,148。
- 固定0.5：宏F1 0.37273→0.47182；聚合阴性误报率11.048%→3.362%。同时recall从0.7880降到0.5545，因此固定0.5的巨大F1提升包含输出概率整体下移的影响。
- 阈值无关宏AP：0.41294→0.43130；说明不仅是阈值移动，排序质量也有小幅真实提升。

## 判断

最有证据的机制是：**新增大量真实组织内负监督 + 去除过强阳性权重，共同抑制稀疏通道的泛化假阳性**。仅凭当前实验不能把两项贡献完全拆开，因为v6同时改变了它们；需要单独消融才可定量归因。外层强度权重变化较小，更可能是次要因素。

逐通道并非全部改善：v6在CD163、CD20、CD45、CD68、CD4、PDL1、SMA等通道明显改善；CD3e、CD45RO、CD8a、FOXP3、Ki67的AP或校准F1部分下降，说明取消阳性加权也牺牲了部分稀疏通道表现。
